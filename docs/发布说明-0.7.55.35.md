# NewFolder3 0.7.55.35

日期：2026-11-16；作者：John Smith / Yuzi。

## 本次修改

1. **开门后不进门**：旧逻辑的导航失败会在下一帧重新开始局部重试，任务本身没有持续失败预算。本版保留正常房间导航，失败或连续无有效位移后改用有界、可取消并校验终点的路径恢复；预算不会因房间切换或局部导航重置而刷新。恢复仍失败时记录原因并按当前模式的失败策略收尾，不再无限原地循环。
2. **副本时间结束后的循环**：本次副本独立记录原生倒计时，确认到期并稳定退场后补记失败，即使没有 DutyWiped 事件也能交给原有失败重开流程。失败不计成功次数；成功事件、人工停止、诊断保留、任务存档归属和独立尾王免删档限制继续生效。未知退出及仅有掉线不自动冒充超时。
3. **BMR 回放联动**：默认在运行任务时开启 BMR 自动录制并回读确认，提供开关。导出改为后台任务，将对应日志时段的回放一起打包，支持绝对自定义目录，提供SHA256与快照状态清单。缺少/锁定回放会提示；不停止或重启现有录制，不宣称写入中的回放完整。

本版不调整职业差异、拉怪阈值或空房策略，不处理暂缓的20层非致死首领问题。AE空版本号诊断异常仍为已知问题。
