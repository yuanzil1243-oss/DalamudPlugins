# 直暴播报

在战斗中把自己造成的直击、暴击和直击暴击写入 Dalamud 聊天：

默认输出示例：

```text
技能名称 直击 12,345
技能名称 暴击 23,456！
技能名称 直暴 34,567！！
```

使用 Dalamud 的 `IFlyTextGui.FlyTextCreated` 读取本地化技能名、伤害值和 `FlyTextKind`，结合游戏伤害飘字入口判断来源为本地玩家；仅输出三种指定命中类型。不会向游戏服务器发送数据。

输入 `/zhijibao` 切换播报开关，输入 `/zhijibao config` 打开设置。

设置窗口允许统一修改技能名/类型/伤害之间的间隔符，并为直击、暴击、直暴分别设置整行文字颜色和伤害末尾符号。颜色使用游戏 UIColor 色号，0 表示默认聊天颜色。可在设置窗口或输入 `/zhijibao test` 预览效果。

每次战斗结束时会在聊天输出分隔文本；战斗中死亡时也会输出。若死亡同时结束战斗，只输出一条分隔文本，避免连续重复。

卫月插件库地址见仓库根目录 README。源代码与构建说明位于本项目目录。
