# NewFolder3 0.7.55.2302

本版基于官方 0.7.55.23，统一模式续打、保档及循环收尾，并修复最终领奖后的等待和分数板衔接。沿用原库链和名称 NewFolder3，不清理用户配置、地图缓存或暂停记录。

- 副本内先选地宫和模式，再点“继续探索”，无需选槽位。普通下底、自由探索也可在副本外选择已有存档续打。
- 当前续打达到目标计为第1轮；设置3轮即当前成功加后续2轮。死灵术士重开从1层开始；普通下底用最高可新建起点；自由探索续打只选结束层，重开用不超过终点的最高合法起点。
- “保留存档”默认关闭。勾选后关闭无限和多次循环，完成或失败后退本保档停止；运行中不能更改这项删档权限。未勾选可按原模式清理本任务绑定档后重开，失败不消耗成功轮数。
- “下底领奖后自动退本循环”总开关保留，只控制最终奖励层的自动退出和循环。关闭时在最终奖励处停留；其他续打、保档和非最终层段规则独立生效。开启且保档时，领奖退本后保档停止。
- 挖宝只能续所选21–30或31–40；聚魔柄只能续死宫51–60、天宫／妖宫21–30；原准备档采集只接受1–30层。死宫／天宫职业范围沿用原版。新建起点仍须游戏原生解锁。
- 未选槽的副本内续打，出本后重新读取原生存档列表，唯一核验对应层段后才绑定；匹配不唯一或来源改变则保留全部存档并停止，不猜槽位。已有档启动及暂停续跑仍精确验证原槽位、角色和职业，删除后仍须读到同槽为空。
- 金／银／铜箱等沿用所选模式预设；续打攻略可调整宝箱，保留此前铜箱可编辑修复。组末暂停、取消暂停及解除续跑锁定复用同一任务流程。
- 说明页最底部新增简短使用规则，所有功能开关都放在其上方；以后新增控件也必须放在说明文案之前。移除AE长篇介绍，精简相关提示，移速说明包含最大加速度。

最终奖励的收尾顺序：原版确认领奖 → 退出奖励房 → 处理分数板及确认 → 回入口 → 验证任务存档并按保档设置处理 → 计轮 → 按所选模式决定重开起点。切图、人物暂未就绪或结算窗口加载中只等待，不提前判定完成。死宫200、天宫100、妖宫100均接入。

保留原移速及最大加速度、最终奖励层移速、仅地宫内GCD保护及等待秒数、防踢、输出联动、聚魔柄兑换、天宫魔石和两套签名地图。没有额外修改原作者战斗、Boss、寻路、探索或道具策略。构建和离线验证不等同游戏实测。
