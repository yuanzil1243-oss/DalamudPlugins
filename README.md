## 本版使用规则

- 本内先选地宫和模式，再点“继续探索”，无需选择槽位。普通下底和自由探索也可在本外选择已有存档续打；固定层段模式只能接续对应层段。
- 当前续打完成目标算第1轮；3轮即当前成功加后续2轮，失败不扣成功轮数。死灵术士重开从1层，普通下底从最高可新建起点；自由探索续打只选终点，重开从不超过终点的最高合法起点开始。
- “保留存档”默认关闭；勾选后关闭无限与多次循环，完成或失败退本保档停止。运行中不能更改这项删档权限；只处理经核验绑定的任务存档，来源不明或匹配不唯一则保留全部存档停止。
- “下底领奖后自动退本循环”总开关仅控制最终奖励层收尾；关闭时留在最终奖励处，其他续打、保档及非最终层段规则独立生效。开启后按领奖、退出奖励房、分数板结算、入口核档、计轮及所选模式重开的顺序执行。
- 组末暂停可原位取消；暂停生效后可继续原任务，或在本外解除续跑锁定并保留存档。金／银／铜箱设置保留，续打攻略可编辑宝箱。
- 说明页最底部提供简短规则；所有功能开关位于这段文案上方，未来新增开关也遵循此顺序。AE长篇介绍已移除。

## 更新与保留数据

- 升级前停止探索并停用旧 NewFolder3 开发加载项，再通过本库安装或更新；同一时间只启用一个 NewFolder3。
- 不要删除 `pluginConfigs/NewFolder3.json` 或同名目录。配置、地图缓存和暂停记录保留；旧续打记录不会自动取得新增删档权限。
- 内置移速与最大加速度、普通层和最终奖励层许可保持；Boss、出本或停止时恢复。请勿同时启用其他移速工具。
- GCD保护只在地宫内生效，等待秒数1–300（默认6）；完全停手请关闭该独立开关。AE／自定义输出联动、输入防踢、聚魔柄与天宫魔石规则保持，服务端防踢效果仍待验证。
- 妖宫21–30、31–40两套地图随包提供并验证原签名，没有恢复私人服务器的同步接口。
- 原作者Boss、机制、战斗、导航、普通层探索、道具及官方.23出口路由实现保持。完整构建0错误、36项既有警告；未安装、重载或操作用户游戏。
