# NewFolder3 0.7.55.2205

基于官方 `0.7.55.22`（`e578aaec1b58945a8bf6868a5c8ec2baae8bc50b`），保留官方副本内战斗、探索、道具、寻路、机制和奖励实现。本地功能通过 `LocalExtensions/` 和可重套接入补丁维护，旧 `.83-final-local` 单独归档。

## 本版改动

- 修复通关退本确认后，已识别的分数板结算“退出”被旧回执阻断。有限次数、无限循环及本次后停止共用修复，完整识别、稳定等待、节流及存档保护保留。
- “本组十层出本后暂停”点击后在原位置变为“取消暂停”，生效前可撤回，继续原任务和次数；已停止的暂停任务仍使用原有继续／保档解锁。
- 新增循环刷强化／聚魔柄：自建死宫51–60、天宫／朝圣21–30，银箱必开；朝圣原挖宝21–30也可单独启用兑换。默认双强化50、每批最多4，按保留值限制数量。未知菜单或交易结果停止；暂停不丢弃进行中交易回执。
- 移速起步即达玩家设定速度（最大加速度），沿用原开关与0.10–10.00倍率，1.00倍也支持直接起步。普通层与最终奖励层许可、Boss交接和停止撤销保留，不增加选项；原生零速和移动限制仍有效。
- 精简移速、防踢、领奖后循环、GCD及等待秒数的悬浮说明。

保留当前GCD保护与1–300秒等待设置、AE／自定义输出、续接宝箱独立配置、普通下底、自由探索、输入计时器防踢、确认败北后自建档重试、终局领奖收尾与两套签名地图。GCD保护不限场景、探索或输出插件状态，暂停／停手不会关闭它，完全停手须关闭该开关；它不修复Boss初始化根因。服务端防踢效果仍待实测。

使用方法见[使用与换版说明](docs/使用与换版说明.md)、[聚魔柄说明](docs/聚魔柄循环移植与验收.md)；后续维护见[扩展壳规则](docs/本地扩展壳与更新规则.md)。检查结果与未测范围见[验收记录](docs/验收记录.md)。构建与离线模拟不代表已验证游戏内起步、刹停、NPC交易或完整循环。

## 构建与重套

使用.NET SDK 10.0.401、Dalamud API 15开发程序集，初始化固定OmenTools子模块 `6b8f1244bee6a8eca741b8c27e1cfc229ceef66c` 后执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Local.ps1
python scripts/test_overlay.py
```

原生起步磁盘契约检查为可选附加项，`SPEED_START_AUDIT_EXE` 指向当前游戏EXE、`SPEED_START_AUDIT_JSON` 指向 `audit_native_start.py` 的本地输出后再运行移速检查。普通托管检查不需要游戏进程；签名或完整函数指纹不匹配时拒绝启用，不能猜地址继续。

`NewFolder3-release.json` 保持官方基底原文件供溯源。有效库链始终为仓库根目录 `pluginmaster.json`，不另换仓库或加插件名称后缀。约定本地目录保留与发布同字节的运行包、源码包和扩展壳。换版保留配置、地图、暂停记录和游戏存档，禁止删空配置作为常规修复。
