# NewFolder3 使用说明

正式版：0.7.55.35；测试版：0.7.55.38；作者：John Smith / Yuzi；整理日期：2026-11-17。

.38需主动接收测试版本；本次两项修复见[测试版发布说明](发布说明-0.7.55.38-测试版.md)。本页下方保留.36引入的玩法说明，.38在此基础上修复删档入口和运行开关。

## 运行环境与安装

Windows x64、Dalamud API15、.NET10。库链安装地址见仓库首页。需要自行启用 vnavmesh、兼容版本的 BMR 及职业循环插件。本地安装时完整解压安装包，七个 DLL 与 NewFolder3.json 保持同目录，添加 NewFolder3.dll。停止旧任务、停用旧条目后再切换，不同时加载同名版本。

## 用户此前报告的测试环境

- AE：启动优先选中带有攻击头标的敌人；主动攻击须能够开启。
- BMR：🦌佬版，危险区距离 2。
- 遁地 -7；移速 2.0；防击退；强制移动。
- 91–98 层附近接战上限 2。
- 长臂猿 +3；目标圈半径扩大 3。用户认为这两项不开应不影响，未作独立对照验证。

以上是测试环境记录，不是本包自动启用的设置，也不代表其他环境已经验证。

## 自动输出与目标

自动输出下拉列表可选择 AEAssist，联动主运行、主动攻击及停手。使用内置项无需填写自定义启停指令；不要把目标选择器开关填到停手指令。本插件自己选择策略目标，不依赖 AE 主动选怪器；另开选怪器时观察是否抢走目标。

## 91–98 层与慧敏

优先击杀开门，允许同房间附近边打边补到上限，不跨房找怪、不等凑满。开门后按前往门房间的路线范围探索补箱。慧敏确认生效后停止主动加怪，处理已有接战目标；不要把切色后在途技能或范围技能结算误认为主动选新怪。

## 99 层与独立尾王模式

先取得有效光暗 Buff 并选好对应 Boss，再开放输出。血差达到 18 个百分点且当前攻击方向会扩大差距时准备换色，仍可输出；达到 24 个百分点才停手。正在缩小差距时不因绝对差距大而反向换色。

吸收以太、束缚/锁链等硬性机制优先；其他空间机制依据 BMR 实时安全路径接管取色，取得实际颜色后交回。无法核实安全路线时等待，不保证所有场景都有可用路线。已发出的技能、DOT、人偶伤害无法撤回，切色后旧目标短暂零伤害仍可能出现。

尾王模式是无存档独立练习：需要先解锁对应歼灭战，选择固定队伍进入；不选择或删除普通地宫存档，通关与退场后计练习次数，不算完整 1–100 登顶。

## 普通流程与存档

普通完整流程按自身存档策略收尾：中间十层接续保档；终轮完成现有验收后，要求清理的任务自有存档先验证删除，再进入通关暂停。未知来源或外部存档继续受保护。独立尾王免删档不影响普通模式的清理规则。此版该修复尚未在完整爬楼后实测。

## 进门导航与副本超时

开门后继续按现有路线前往传送门。普通导航明确失败或持续约12秒没有有效位移时，进入独立恢复：使用可取消寻路、校验实际路径终点，尝试门圈附近点及短距离接近点。单次路径查询最多8秒，最多5次查询，恢复活动时间最多60秒；等待旧寻路结束、网格就绪和无位移移动也有单独上限。战斗与机制避让会暂停恢复，门圈内正常等待不算卡住；门房内迟迟没有门实体、持续无法取得门位置也会记录并结束等待。

恢复耗尽时不再无限原地重试。完整攻略/自由探索按既有失败策略退本、核对所持存档并重开，不计成功次数；保留诊断记录、外部存档保护及来源校验，其他模式保持停止检查的限制。并非所有寻路或外部插件故障都能自动修复。

副本时间耗尽被送出时，即使未收到 DutyWiped，也会依据本次副本的最近原生计时、到期时间和稳定退场状态补记失败，再走原有退场与存档核验、失败循环。仅有掉线、未知退本或旧计时不能被当作超时；成功事件优先，失败不占用成功循环次数。独立尾王模式仍不进入普通删档流程。

## BMR 自动回放与一键导出

- 「探索配套」中的「任务期间自动开启 BMR 回放」默认勾选。运行任务时通过 BMR 配置接口开启 AutoRecord，并回读确认；缺少 BMR 或接口不兼容会显示状态。仅设置自动录制，不代替实际回放文件验收。
- 保留 BMR 原有匿名化、保留数量、录制格式和目录设置；不发送回放停止命令。取消勾选只停止本插件的自动开启行为，不会把 BMR 已有的自动录制设置关掉。
- 点击「导出日志与回放」，后台把最近三天仍保留的运行日志及其时间范围内的 BMR 回放打包到桌面。支持 BMR 配置中的绝对自定义回放目录，默认使用同一卫月配置根目录内的 BossModReborn/replays。
- 包内包含 DeepDungeonRuns、BMR/replays 和「打包清单.json」。清单记录快照的 SHA256、字节数、匹配时间范围、复制期间是否变动，以及缺失/无法读取等警告。未找到回放时仍可导出日志，并明确提示。
- 导出不暂停或重启正在录制的回放。正在写入的文件只复制导出开始时已有的字节；所有回放均注明尚未验收完整性，不会因文件非空或大小稳定而称为完整。异常后建议退本、等待回放收尾再导出。

## .36测试版新增用法

自由探索新增「探索埋藏的寶藏」开关，默认关闭。优先用感知，本层系统提示有则找实际指示点踩出开箱，无则正常开门下层；没有感知时用本机PalacePal候选点。普通层组第8、9层不新用，91–98可用。消息缺失不等于无宝藏，用药15秒仍未知会留诊断后放弃本层可选挖宝，迟到的本层阳性可恢复。

91–98清旧仇恨并开门后，剩余时间大于「10分钟+每个后续普通层2分钟」时允许宝藏绕路；预算耗尽停止挖宝，普通补给箱仍沿去门路线。计时未知不开绕路。候选点并非完整覆盖，不附个人缓存或地图。

失败保留现场的旧HoldOnFailure入口已删除；普通死灵失败删本任务存档并确认槽空后，从1层继续成功次数目标。10秒无真实进展恢复，最多3次/总活动120秒；无法安全验证会明确报错。陌生确认、无法证明归属的存档不盲删。独立尾王仍免普通删档。

本测试版：机制134、契约145、退场22，共301项离线回归通过；游戏验证待完成。详细测试重点与已知边界见测试版发布说明。
