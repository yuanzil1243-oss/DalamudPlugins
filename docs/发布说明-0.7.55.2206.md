# NewFolder3 0.7.55.2206

基于官方0.7.55.22，在扩展壳内修复聚魔柄出本过图误停，并为天宫聚魔柄模式加入独立魔石规则。

- 聚魔柄职业支持沿用原版启动检查，移除循环和兑换中的重复职业一致性检查。出本过图、角色暂未加载或ID暂不可读时等待，恢复后继续；真正换角色仍停止并保留存档保护。
- 仅天宫聚魔柄21–30适用新魔石规则：21–29层实际溢出时沿用原流程使用；30层进入Boss战后，按冷却逐颗使用库存，Boss死亡、通关或库存耗尽后停止。妖宫、死宫和天宫其他模式不套用。
- 魔石继续使用原道具请求与确认通道，提交及确认后至少间隔10.5秒，保留施放、动画锁、机制禁用和库存确认。这是保守请求间隔，不读写或绕过服务器冷却。
- 正常通关后仍先退本、核验清理本任务存档，再判断强化与兑换，最后计数并重新挑战；兑换门槛和每批上限不变。
