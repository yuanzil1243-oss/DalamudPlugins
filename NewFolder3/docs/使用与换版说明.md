# NewFolder3 0.7.55.2102 使用与换版说明

基于官方 0.7.55.21，沿用 .2101 扩展壳，新增默认关闭的“下底领奖后自动退本删档循环”，保留移速、AEAssist 输出控制、指定既有存档、继续探索、最高起点普通下底、自由探索、默认关闭的防踢和签名离线地图。原作者副本内战斗、探索、道具策略、寻路与奖励领取使用 .21 实现；仅在终局奖励完成确认后，按开关决定是否继续原退本收尾流程。日志导出沿用 .21 附带最新深宫 ARR 回放的功能。通过原库链分发，新增终局收尾流程仍待游戏内实战验证。

## 本次换版修复

旧天宫分支曾把“自由探索”写为 Farming.Mode=4、“尾王”写为 5。官方和 1902 仅识别 0–3，因此即使更换 DLL 仍会因 Farming configuration is invalid 无法加载。

2001 在读取旧配置前先按 SHA-256 备份原文件，再转换已知旧值。自由探索设置转存为扩展字段，不再占用官方模式枚举；其他模式和未知未来值不擅自重置。旧尾王模式回到深层攻略待用户手动选择，不自动开跑。备份位于插件配置目录 LocalCompatibilityBackups；程序不会删除地图、暂停记录、研究数据或游戏原生存档。

## 日常使用

- 移速仅有启用和倍率设置。普通层且探索程序运行时生效；Boss 层、副本外、停止和卸载时释放；下一组普通层重新生效。请先停用其他移速工具，默认关闭。
- 继续探索按钮在已进入深宫且程序未运行时显示；也可使用 `/newfolder3 fsd continue`。它直接继续当前层组，不要求用户提供槽位。
- 普通下底使用所选深宫支持的最高新建起点。
- 自由探索可选择合法的新建起点、结束层组和循环次数；完整选定区间才算一轮。既有存档只完成当前一遍，绝不自动删除、重建或改用另一槽位。
- 游戏存档数据尚未读取时，先打开对应挑战面板；死宫请打开挑战“死者宫殿”读取数据。
- 防踢开关默认关闭；仅 FSD 运行、深宫内、非战斗且原地静止 4 分钟后发送当前位置更新包，不改变坐标，服务端效果尚待实战验证。
- “下底领奖后自动退本删档循环”位于“说明”页移速、防踢下方，仅有一个开关，默认关闭。开启后，原版确认全部终局奖励已领取，再自动退本并返回入口；只删除本任务新建且校验匹配的存档，确认该槽为空后，按 FSD 已有循环次数或无限循环设置继续。达到次数上限则在本轮退本清理后停止。
- 奖励未确认、任务异常、诊断保留现场时不会由此开关跳过验收或强制收尾；已有存档与“继续探索”仍保档停止，不纳入删档循环。开关关闭时保持官方原有行为，不影响原本就会退本的地宫流程。

## 详细地图

内置妖宫 21–30 和 31–40 两套原始签名地图，数据版本 2026-11-23.1。新用户离线可用；用户已有更新且有效的数据时优先使用。内置文件在插件目录直接读取，不覆盖用户缓存。此包没有恢复原作者私人服务器的自动下载接口。

地图目录取自卫月提供的主插件实际安装位置，兼容卫月将依赖程序集从流中加载的方式；不依赖游戏工作目录，也不要求删除已有配置。

## 保数据切换与更新

不要删除 pluginConfigs/NewFolder3.json 或整个 NewFolder3 配置目录。安装目录中的旧 .83 与官方 .20 同名，不能仅复制一个新 DLL 后让加载器自行选择。

关闭游戏后，可用包内 tools/Repair-NewFolder3.ps1：

```powershell
# 默认只检查；不写入。
powershell -ExecutionPolicy Bypass -File .\tools\Repair-NewFolder3.ps1
# 切回已安装的官方版：禁用本地开发加载项、保留配置、隔离旧 .83 二进制。
powershell -ExecutionPolicy Bypass -File .\tools\Repair-NewFolder3.ps1 -Mode Official -Apply
# 使用新本地版：替换为实际 DLL 完整路径。
powershell -ExecutionPolicy Bypass -File .\tools\Repair-NewFolder3.ps1 -Mode Local -LocalDll 'C:\Plugins\NewFolder3\NewFolder3.dll' -Apply
```

工具先校验备份，再修改 NewFolder3 的加载选择；其他插件保持原设置。旧二进制移入 XIVLauncherCN/backups/NewFolder3-switch-*，不删除。配置目录、地图缓存和续打记录保持原位。写入失败会尝试恢复本次修改。若要手动恢复配置备份，也必须先关闭游戏。

游戏运行时使用卫月插件管理器先卸载旧 NewFolder3，再加载目标版本；不要直接编辑正在运行的卫月全局配置。不要同时启用多个 NewFolder3。通过本库安装时使用当前发布包，停用旧的开发加载入口；构建工具本身不自动发布库链。

版本规则：官方 .20 的第 1、2 个修改版为 .2001、.2002；官方 .21 的首个修改版为 .2101。更新扩展壳会先检查补丁上下文；发生上游冲突时停止，不覆盖原作者代码。
