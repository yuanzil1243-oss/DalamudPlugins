# Yuzi · Dalamud 插件库

本库当前发布基于原作者新版重新接入扩展的 NewFolder3，提供对应源码、许可证和校验信息。

## 添加插件库

在卫月第三方插件仓库设置中添加以下地址，保存并刷新：

```text
https://raw.githubusercontent.com/yuanzil1243-oss/DalamudPlugins/main/pluginmaster.json
```

## 更新与保留数据

- 升级前先停止探索并停用旧 NewFolder3 开发加载项，再通过本库安装或更新；同一时间只启用一个 NewFolder3。
- **不要删除** `pluginConfigs/NewFolder3.json` 或同名配置目录。新版先备份再迁移已知旧模式值，保留地图缓存和暂停/续打记录。
- “继续探索”可调整金／银／铜箱并立即影响后续选箱；选择按实际深宫独立保存，更新重载后继续复用，不覆盖原模式配置。续接仍只完成当前组后正常出本保档。
- 内置移速默认关闭，普通层和最终奖励层满足条件时启用，Boss、过场、副本外及任务停止时释放。请勿同时启用其他移速工具。
- AE 支持本地安装，控制记录不再读取加载器清单或版本；保留原通信端点、手动优先和停止恢复，不改 /aestop。可选输出诊断异常不影响主循环；若旧会话已有移速故障锁，先停止任务并卸载旧插件再加载本版。
- GCD 停滞保护默认关闭，提供等待秒数（1–300，默认6）；选中同一可攻击敌人后长时间无 GCD，就在实际可用时尝试一次。不限场景、FSD 或输出插件，AE／Custom 同样适用。暂停、停手和机制故障不关闭独立保护；完全停手请关闭开关。
- 本组出本后暂停覆盖普通下底、自由探索、挖宝和准备档；副本外可解除续跑锁定并保留游戏存档，再选择其他任务。
- “下底领奖后自动退本删档循环”默认关闭，位于说明页移速、防踢下方；只清理本任务创建并校验匹配的存档，按已有循环设置重开，已有存档与当前副本续接保档停止。
- 两套地图随包提供，保留签名与哈希验证；没有恢复原作者私人服务器的自动同步接口。

- 防踢读取原生输入计时器，超过 60 秒向本游戏窗口短按 Ctrl，每分钟最多一次，并核对客户端计时器；不再发送静止位置包，服务端效果待测。
- 死灵术士、普通下底和自由探索的正常自建档明确败北后退本、校验删档并从原起点重试；失败不占成功次数，完整范围才计一轮。已有档、暂停和异常保护保留。终局领奖后的多轮需开启既有自动收尾开关。

- .2205 修复退本确认后结算退出被旧回执阻断；本组后暂停在原位置切换为取消暂停，撤回后仍按原任务和次数执行。
- 新增独立刷强化兑换功能，保留旧模式配置编号与官方副本内逻辑；使用规则、强化门槛、批量与不确定结果处理见当前使用说明。
- 移速直接起步由原开关统一控制，普通层与最终奖励层均保留，1.00倍也支持；不新增选项。设置悬浮说明已精简，新功能待游戏实测。
