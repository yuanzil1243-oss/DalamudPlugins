# NewFolder3 0.7.55.34 本地候选版

整理日期：2026-11-13。此版完成离线构建与回归验证，尚未游戏内复测。

## 1. 修复清理存档与通关暂停的顺序

最新日志对应 PT 挖宝藏31层起点的一组十层，而不是完整1–100或独立尾王练习：北京时间17:25:29.441完成40层、17:25:39.141休息区退出完成、17:25:39.143进入通关暂停；17:30:58.427在暂停中停止。接着17:31:07.068从21层创建失败，提示没有空存档槽。旧流程的暂停分支位于删除之前，能够解释这次存档残留；不把它写成尾王免存档分支误入的既定事实。

- 对原策略要求清理的完整一轮，先验证本任务拥有的存档已删除，再进入“通关后暂停”。暂停中停止也不会留下尚待执行的本轮清理。恢复只结算原尝试，不重复删档或计次。
- 普通1–100攻略中途每十层仍保留接续存档；通过100层并完成现有领奖/退本验收后才执行终轮清理。
- 删除失败、来源不明或验证异常时停止，不假装已删、不计成功。
- 原有复用预备档、外部档保护和指定诊断停止边界继续有效；本次不是任意存档清空功能。
- 只有合法的“尾王模式 + 无存档 + 99层独立练习”走免存档流程。普通场景拒绝尾王/无存档计划，尾王场景拒绝普通带档计划，策略层再次拒绝异常组合。
- 增加 `owned-save-cleanup-started/completed`，暂停事件包含是否要求清理、是否完成清理。

## 2. P01：首次输出前取得实际颜色

- 无有效光/暗Buff或颜色矛盾时，不向Boss开放输出。引擎在场景Tick之前另加门控，避免先开启AE、再由场景停手的首帧漏洞。
- 未开战、双Boss均满血且没有敌方读条时，在已核对99层场地内允许使用颜色地板几何和原生视线查询启动首次取色。开战/出现读条/血量变动后，恢复要求BMR活动战斗模块和实时路径安全接口。
- 先读实际Buff，再应用对应目标，最后开放输出。优先小怪仍沿用原规则，不能把该例外用于Boss。
- 颜色改变当帧重新扫描目标，不再等待100毫秒HP扫描节拍；诊断记录颜色观测、目标应用、输出资格以及实际输出开关事件的时间。
- 不增加等待弹道结束的固定停手；用户已明确接受切换后已发出技能对旧目标造成0伤害。现有DOT、人偶、施法和在途结算仍不能撤回。

## 3. P02：18准备、24停手与安全取色衔接

- 当前颜色继续攻击会扩大失衡时，血差达到18个百分点即保留换色请求并寻找机会，仍可输出；达到24个百分点才执行停手。两端使用精确比例而不是界面取整值。
- 正在攻击高血量Boss、缩小差距时，不因绝对血差较大反向换色或停手。已倒地Boss、无色等约束单独处理。
- 吸收以太双Boss/辅助施法重叠与连续读条保留结算保护，另检查角色束缚4510、锁链4562；期间交还移动且不花费恢复预算。
- 其他空间机制不再仅凭固定缓冲时间禁止接管。取色候选来自已核对的10块光/暗地板多边形，搜索其中与BMR当前安全判断相符的内点，并检查原生视线、全段步行采样及终点余量。当前点不安全、没有可靠安全接口或直线路线不可核对时，继续交给BMR。
- BMR安全IPC提供的是布尔判断，并非完整危险区形状；其禁区包括颜色约束和已发布的未来禁区。这里保守检查其当前全部禁区，不假设“站定等于安全”，也不宣称实现任意绕障寻路或精确预测所有未来结算。
- 每次候选搜索最多6点/384次安全查询，间隔500毫秒；移动中每150毫秒重新核对路径。安全变化即释放移动。无可用路线时记录原因和请求时长。
- 每次主动尝试最多10秒、3秒无推进则释放，失败重试冷却2秒。提前准备失败不会直接终止正常输出；进入24/无色等必要恢复时有独立新预算。必要恢复最多35秒主动接管、120秒非硬机制等待或3次失败，耗尽时停止并记录原因；硬机制等待不计这两项时间预算。
