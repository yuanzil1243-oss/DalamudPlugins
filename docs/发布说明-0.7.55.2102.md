# NewFolder3 0.7.55.2102

发布日期：2026-11-24。官方基底 0.7.55.21，提交 a71af60a01682eb76cd6d1ec46ac971b88f75d5a；本版为 .21 基底的第二个修改版本。

- 新增“下底领奖后自动退本删档循环”开关，位于“说明”页移速、防踢下方，仅提供一个开关，默认关闭。
- 开启后，原版确认终局奖励已全部领取，再继续正常退本、返回入口、校验并删除本任务创建的存档；确认该槽为空后，按现有循环次数或无限循环设置重新挑战。最后一轮也先退本清理再停止。
- 已有存档和“继续探索”只退本、保档停止；领奖未确认、任务异常、诊断保留现场时，不由该开关强制收尾。
- 保留原作者 .21 的副本内战斗、探索、道具策略、寻路、终局奖励领取和日志导出附带 ARR 回放功能。只增加奖励确认后的可选调度接入。
- 保留移速、AEAssist、指定存档、最高起点普通下底、自由探索、防踢、进退本界面提速，以及妖宫 21–30、31–40 两套签名离线地图。
- 名称为 NewFolder3，继续使用原仓库和原库链；旧版发布物保留在独立版本目录，不参与当前更新。

## 验证与边界

Release/x64 构建 0 错误，36 项上游既有警告；181 项契约检查（含新增 40 项终局收尾检查）、96 项移速离线检查，以及保数据换版工具检查通过。扩展壳当前基底重套、模拟下一版本和代码冲突拒绝演练通过。

新增领奖后退本、删档及重新挑战的完整流程尚待游戏内实战验证，防踢服务端效果也待实测。发布过程不切换当前游戏插件，不启动探索，不清空用户配置、地图缓存或续打记录。
