# NewFolder3 0.7.55.36 测试版

发布日期：2026-11-17；作者：John Smith / Yuzi。

本版通过离线构建与回归，尚未游戏实测。正式通道继续为 0.7.55.35，只有主动接收本插件测试版本的用户更新到 .36；没有将历史通关记录视为本版验证。

## 自由探索可选挖宝

在「自由探索」内勾选「探索埋藏的寶藏」，默认关闭，偏好按模式独立保存；不新增重复模式，不改变所选起止层、续档和计次规则。

- 有感知道具、没有已有感知效果时优先使用。普通十层组只在第1–7层新用，第8、9层不新用；已有状态仍利用。91–98层可新用，99首领和100奖励层不挖宝。
- 本层系统消息7272判为有、7273判为无。有则寻找实际指示点、踩出并开箱验收；无则终止本层可选探索，正常清怪开门后前进。文本缺失、光柱未出现及超时均不冒充「无宝藏」。
- 本次用药15秒仍没有阳性/阴性文本及实际指示点时，记录「结果未知，策略放弃」，避免无限等待；本层迟到阳性或实际指示点可恢复挖宝。时间预算耗尽的放弃不因迟到阳性恢复。
- 无感知时沿现有 PalacePal 历史候选点搜索。点位取决于本机可读取数据，不承诺所有房型全覆盖；包内不附个人地图数据库，不把21–30/31–40固定地图套给其他层段。
- 91–98仍先击杀开门并清旧仇恨；时间足够时允许为宝藏绕路。判定标准：为99层及奖励预留10分钟，再为当前层之后至98层的每个普通层预留2分钟。例：91层需剩余时间大于24分钟，98层需大于10分钟。计时未知不开放绕路。该预算是保守策略默认值，不是通关用时保证。
- 预算耗尽时安全取消旧搜索并推进；普通补给箱仍仅在前往门房的路线范围内，不因挖宝放宽。不会为了凑接战数跨房拉怪。
- 数量分布只作提示，不用「已挖5个」或固定分段推断覆盖本层系统结果，不按宝藏数量提前完成整轮。

## 失败后重新开始

删除 HoldOnFailure 在配置、启动请求、命令、运行状态和失败分支中的活动入口。旧配置即使带此字段也不能再启用保留失败现场。

普通死灵术士失败后退本，验证本任务所持存档、删除并确认槽空，然后从1层继续原成功次数目标；失败不算成功，也不重置已完成的成功数。自由探索按其既定起点和外部存档授权重试；独立尾王仍不进入普通删档流程。

删档只依据实际UI阶段或真实向NPC靠近续预算，重复请求不算进度。10秒无推进进行恢复，最多3次，总活动预算120秒；过场或角色未加载时暂停计时。删除确认只派发一次，陌生确认不盲点。恢复耗尽会明确报错、保留存档归属，不会无限等待、假删成功或碰其他槽。

## 目标与兼容修复

- 61–69层「得到宽恕的主见」（几千针刺）进入优先击杀，和食岩狼同级，拟态怪更高；危险怪单独接战，保留BMR机制避让，不改其他层的目标规则。
- 读取AE等插件的诊断版本号时兼容空字符串/异常，不再让元数据异常打断当帧后续控制。
- .35已有的进门导航恢复、副本超时失败循环、BMR自动回放与日志导出保留并回归。
