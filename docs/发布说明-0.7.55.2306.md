# NewFolder3 0.7.55.2306

基于官方 .23，新增持久触发计数、死宫1–50强化预设和只刷强化开关。沿用原库链，插件名称仍为NewFolder3。

- 防击退／吸引、强制移动、GCD停滞保护开关后，同一行淡色显示“触发次数：数字”。三个计数独立累计，关闭开关不清零，重启、正常换版后保留；旧版没有记录的次数无法补算。
- 防击退按已拦截请求统计，相同参数连续短突发去重，不能等同精确服务端技能数。强制移动需实际解除限制并观察到位移，连续受限计一次。GCD补招收到本人技能、目标及请求序号匹配的成功回执才计数；拒绝、超时、重复不计。
- 计数独立保存在pluginConfigs/NewFolder3/LocalExtensions/trigger-counts.json及.bak，采用原子写入、有效备份恢复和失败重试。正常更新无需手动搬文件，不得删除配置目录换版；个人计数不会打入安装包。原生回调后下一帧落盘，崩溃前极短窗口仍可能损失未保存事件。
- 死宫强化／聚魔柄保留默认51–60，新增1–50预设。中间四组通关接续本任务原档，不计轮数、不删档、不兑换；50层完成才计一轮并收尾。失败先核验原档，能继续就续打，不能继续才核验清理本任务档重开，失败不扣成功轮数。
- 强化／聚魔柄新增“不兑换聚魔柄（只刷强化）”，覆盖死宫两预设及天宫、妖宫该模式。跳过启动前和出本后的兑换，保持层段、箱子偏好及循环次数。默认关闭，原有兑换门槛和数量保留，独立挖宝模式的兑换设置不变。
- 1–50预设的继续探索仅接续1／11／21／31／41组，中途暂停恢复保持原层段和兑换选择；下一轮从1层开始。1层入场不沿用51层的强化余额门槛，实际解锁和入场仍由游戏判定。
- 继承地图校验、1.8米共同覆盖盲踩、自由探索指定盲踩层数、聚魔柄输出用药、移速与最大加速度、地宫内GCD保护、防踢、AE协调、续打、保档、暂停和失败重试。两套2026-11-25.1原签名地图随包；所有控件仍放在底部说明上方。

新增层段和兑换编排仅作用强化／聚魔柄。原作者Boss、战斗、选敌、探索、导航和入退本控制器保持，普通下底、死灵术士、自由探索原有规则保持。更新保留配置、地图缓存、暂停记录和计数文件。
