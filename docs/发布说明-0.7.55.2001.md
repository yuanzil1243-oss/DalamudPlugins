# NewFolder3 0.7.55.2001

发布日期：2026-11-24。官方基底 `.20`，提交 `ac90ff5e958c2eb236d5afa380d244d8217ac215`；本版为该基底的第一次修改。

- 重新接入 1902 扩展：内置移速、AEAssist 输出控制、指定已有存档、继续探索和最高起点普通下底。
- 新增自由探索：合法起点、结束层组、循环次数和分地宫选项；完成区间计一轮，已有存档单次保档停止。
- 内置妖宫 21–30、31–40 原始签名地图 `2026-11-23.1`，离线可用，较新有效缓存优先。
- 修复旧 `.83` 模式配置导致无法加载；先备份再迁移，不删除地图或续打记录。
- 修复卫月从流加载依赖程序集时地图路径为空，改用主插件实际安装位置。
- 去除不可靠的历史资格标记，增加挑战面板读取提示；“本组后暂停”沿用官方。

新增实现集中在 `LocalExtensions/`；25 个明确接入文件之外的官方跟踪文件保持原样。未把旧 `.83` 的副本战斗、探索、寻路及奖励改写套回新基底。
