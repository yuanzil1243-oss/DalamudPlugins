# NewFolder3 0.7.55.2002

发布日期：2026-11-24。官方基底 `.20`，提交 `ac90ff5e958c2eb236d5afa380d244d8217ac215`；本版是 `.20` 基底的第二个修改版本。

- 保留 `.2001` 的移速、AEAssist 输出控制、继续探索、自由层数循环、最高起点普通下底及两套妖宫离线详细地图。
- 新增默认关闭的深宫防踢开关：FSD 运行中、深宫内、非战斗且静止 4 分钟后发送当前位置更新包，不改变坐标。
- 缩短退本、删档和重新进入副本的界面交互间隔；不改副本战斗、探索或奖励流程。
- 清理安装包内插件显示名称，安装后显示 `NewFolder3`。

防踢位置更新包的服务端效果尚未经过游戏内实测，因此开关默认关闭。完整副本流程与奖励领取仍待实战验证。
