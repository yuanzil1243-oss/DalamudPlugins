# NewFolder3 0.7.55.40 测试版

发布日期：2026-11-18；作者：John Smith / Yuzi。

本版基于.39，完成此前尚未发布的公共地图下载功能。正式版保持0.7.55.35，.39继续探索按钮和战斗恢复修正保留。

## 新用户用法

在“挖宝藏”中选择21–30或31–40层，勾选“使用详细地图”。本地没有有效地图时会自动向本插件GitHub仓库请求对应层段，下载并验证原始签名、地图哈希与宝藏统计后保存缓存。无需先使用原版或复制其他人的插件配置。首次下载期间等待界面显示数据版本就绪，再启动FSD；已有有效缓存可离线启动，更新失败也保留已验证版本。

这项开关沿用原有选择，不强行打开已经关闭的详细地图。运行中的任务继续使用启动时锁定的地图快照，不会因后台更新突然换路线。下载失败有状态提示及原有“重试下载”入口；单次完整检查有60秒上限，卸载会取消未完成下载。下载不上传使用者的个人数据。

进入朝圣交错路时，若当前层段缺少有效的本地点位，会在后台读取独立公共缓存或下载历史候选点。单次加载最多15秒，失败冷却一分钟后按需重试；挖宝初始化只在缺点位且下载仍进行时等待。有效的个人点位优先使用，不被公共数据覆盖；公共数据不写入个人采集文件。下载完成会刷新点位索引，后续楼层可直接使用缓存。

## 本次公开的数据

经用户授权，从本机已安装的数据与坐标缓存整理：

- 21–30、31–40详细地图，均为2026-11-09.1：分别42个房间记录、249和245个候选点，连同原始公开签名和宝藏统计一起发布，保留原字节。
- 朝圣交错路十个层段共2,687个陷阱点和80个宝藏历史候选点。21–30层沿用既有异常坐标规则排除210条记录。公共坐标只包含类型及坐标。
- 没有公开角色、账号、聊天、存档、日志、回放、原始导入报告、配置或私钥。用户原始文件不改动。文件清单和SHA256见data/NewFolder3/manifest.json。

其他层段只有上述历史候选点，不能当作拥有21–30/31–40同等详细地图；候选点和历史统计也不能保证本层有宝藏或所有房型均已覆盖。

## 验证与边界

使用全新的临时配置目录，验证两个层段完整下载、签名/统计校验、任务地图快照及离线重启。点位测试覆盖缺失、坏缓存重下、大小/哈希/字段拒绝、并发去重、本地优先、公共缓存与个人文件隔离、失败冷却和卸载取消。另验证签名地图响应体卡住时卸载能取消，避免后台下载永远等待。

离线回归：机制134、契约201（含3项公开数据验收）、退场22，共357项。本版相对.39新增22项。实际GitHub下载和离线重启另作发布后检查；游戏内挖宝效果仍待验证。本版不修改.39的恢复策略，也未处理99层移动偏航。
