# NewFolder3 0.7.55.2103

发布日期：2026-11-24。官方基底 0.7.55.21，提交 a71af60a01682eb76cd6d1ec46ac971b88f75d5a；本版为 .21 基底的第三个修改版本。

- 新增“GCD 停滞保护（测试）”单开关，默认关闭。同一 FSD 批准目标连续满足输出条件 6 秒没有 GCD 进展，尝试一次本职业基础单体 GCD；底层拒绝也不盲重试，后续观察到 GCD 冷却进展后才允许下一次恢复。
- 只对可读取开启状态的 RSR / Wrath / Prome 补打；AE / Custom / INH3 不补打。保留读条、冷却、排队、动画锁、射程视线、停手和机制限制。不切目标、不寻路、不强停移动，不代替完整输出循环。
- 补全各模式“本组十层出本后暂停”：深层攻略、最高起点普通下底、自由探索、挖宝、准备档采集／发现均接入。中途组验证下一组原存档后暂停；循环终点完成原收尾后保存下一轮和已完成次数；准备档按原采集结束点保档。最后一轮和已有档终点不留多余锁。
- 新增副本外“解除续跑锁定（保留存档）”，可另选其他存档／模式。只归档本地任务记录，不删除游戏存档、地图或配置；原版暂停记录继续兼容。异常退出保档停止，不因暂停而自动重试或删档。
- 终局房须原版先确认全部领奖，才响应暂停退出；继续挖宝保留原详细地图选择。原战斗、探索、道具、机制和奖励实现保留，仅加受控调度及可选单次补打。
- 保留全部现有扩展及妖宫 21–30、31–40 两套签名离线详细地图；名称始终为 NewFolder3，原库链不变，历史版本保留独立目录。
