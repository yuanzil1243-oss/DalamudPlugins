# NewFolder3 0.7.55.2202

日期：2026-11-24。官方基底 0.7.55.22，提交 e578aaec1b58945a8bf6868a5c8ec2baae8bc50b；本版为该基底第二个修改版。

- 修复“继续探索”铜箱固定关闭、界面无法勾选及运行时修改未接通的问题。续接后金／银／铜箱可自由启停，立即更新后续目标选择；已经发出的交互不强制中断。
- 续接宝箱偏好按实际所在深宫独立保存，更新、重载或重登后继续时复用。首次只复制同地宫当前模式已有的宝箱选择，没有可靠记录才沿用开金／开银／关铜的旧默认；铜箱仍可主动启用。更新前未保存的临时选择无法恢复。
- 不覆盖原模式、自由探索或最高起点的配置，不改变原死灵术士模式的开箱限制。续接仍只完成当前十层组后正常出本保档停止；埋藏宝藏、跨组循环、删档权限及原安全限制不扩展。
- 完整保留官方 .22 新道具策略、AEAssistV3 识别、普通层和最终奖励层内置移速、GCD 保护、全模式暂停与保档解锁、自由探索、防踢、终局领奖收尾及两套签名离线地图。
- 名称仍为 NewFolder3，原库链不变。历史版本保持独立；运行包不夹带用户配置、存档、日志或临时产物。
