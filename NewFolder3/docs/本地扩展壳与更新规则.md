# 本地扩展壳与更新规则

当前交付：0.7.55.2001；官方基底：0.7.55.20，提交 ac90ff5e958c2eb236d5afa380d244d8217ac215。

## 版本约定

最后一段版本号 = 官方最后一段 × 100 + 本地修订号（01–99）。

- 官方 .20 → 第一次修改 .2001，第二次 .2002。
- 官方 .21 → 第一次修改 .2101，第二次 .2102。
- 主版本前三段跟随官方；禁止用后缀标签替代 DLL/清单的实际程序集版本。
- `scripts/local_version.py` 是规则实现；构建、审计、打包共同使用该规则。需要本地第二次修订时，更新扩展清单的修订号以及工程/插件清单版本，校验一致后构建。

## 布局与边界

- `LocalExtensions/Host`：内置移速；复用已经通过测试的策略核心，仍由普通层/Boss/过场/副本外/停止等条件控制。
- `LocalExtensions/Core`：已有档保护、继续探索、最高起点和自由探索范围策略。
- `LocalExtensions/Runtime`：AE 接管租约和自由探索独立配置。
- `LocalExtensions/Dalamud`：AE、已有档、继续探索、自由探索界面/启动适配、离线地图加载及配置接入。
- `Directory.Build.targets` 仅引入 `LocalExtensions/LocalExtensions.targets`，后者把对应源文件加入各自的原项目；不把私有功能散落进第三方快照。
- 原作者现有的类不是公共插件扩展 API，因此仍需要少量明确接入点。接入点以 `hooks.patch` 导出。这里不是声称未来任何版本都无需适配。
- `FarmingScenario`、暂停、入场/出场控制器、战斗/绕圈/寻路/探索控制器、终局奖励和机制运行时保持官方 .20 原文件；自由探索只在参数与层段决策处接入。
- `FloorWorkPolicy` 的新增分支仅允许自由探索的藏宝选项进入原探索控制器；开箱增强只接入独立运行配置，原开箱算法不变。RunHost 只在场景初始化后追加局部配置调用。

## 生成可复用扩展包

在本工程根目录执行：

```powershell
python scripts/local_overlay.py export --output artifacts/local-overlay-2001
```

结果包括：`hooks.patch`（受限的官方文件接入点）、`additions`（扩展、地图、工具、文档和测试）、`overlay.json`（来源及逐文件哈希）。不含官方私有服务地址、密钥、个人配置或游戏存档。

## 套用下一版官方源码

先在独立的官方源码目录拉取作者更新，然后使用新的输出目录。例：

```powershell
python scripts/local_overlay.py apply --overlay artifacts/local-overlay-2001 --upstream C:/path/to/official-checkout --ref origin/main --revision 1 --output C:/path/to/NewFolder3-next-local
```

工具读取官方版本并计算修改版编号：.20 + revision 2 → .2002；.21 + revision 1 → .2101。

工具克隆指定提交到全新的输出目录，先 `git apply --check` 检查接入点；官方新文件与扩展重名、上下文不匹配或哈希错误时直接停止，不覆盖原工程，不强行套用，也不删除冲突以绕过检查。此时应在新目录审阅差异、更新接入点和测试，再导出新的扩展包。

套用成功只代表源码合成成功。进入新目录初始化依赖并验证：

```powershell
git submodule update --init --recursive
powershell -ExecutionPolicy Bypass -File scripts/Build-Local.ps1 -Package
```

只有构建、回归和源码边界审计通过，才生成本地测试包；仍需用户在合适时机切换并进行游戏内测试。工具不安装、不重载、不启动 FSD，不修改库链或发布仓库。

## 离线详细地图

- 随包两套：朝圣交错路（妖宫）21–30、31–40；当前数据版本 2026-11-23.1，实际覆盖各组非 Boss 层。
- 原始地图、签名和收益数据保持不变。启动仍执行原作者哈希、作用域、模型和公钥验签；失败的地图不能使用。
- 优先读取配置目录里有效的官方缓存；与随包版本比较后只选更新的有效数据。同日期修订号按数字比较，10 晚于 9。未知格式不抢占现有有效缓存。
- 随包地图原地只读，不覆写用户缓存、设置或存档。插件目录只需有读取权限。
- 不再要求“有在线服务地址”才能使用通过校验的本地地图。界面明确显示离线状态，数据随包更新；没有声称已恢复连接作者服务器的自动同步。
- 用官方版正常下载新数据后，可执行 `python scripts/map_bundle.py --source-cache <DetailedMapCatalogs路径>` 更新工程中的随包副本，再进行构建、回归和打包。此命令只读官方缓存。

## 自由探索

独立模式，按地宫分别保存起止楼层、宝藏、金/银/铜箱、开箱增强和循环偏好。普通新建入口只列原版支持的起点：死宫 1/51，天宫 1/21，朝圣 1/21/31/51/71；实际解锁仍由原生入口确认。

其他十层组起点可通过读取、明确选择对应的已有存档续打；该路径只执行一次并保档停止，不参与删档循环。人物、职业、地宫、槽位、进度和行指纹在启动前重新核验。

完整走完范围才计一轮。例：21–50、3 轮需完成 9 个十层组；中间组不计轮数，失败不计成功。新建任务只清理本任务拥有并验证过的存档，不删除另一槽位。终点是正常组末，不使用诊断停止参数，最终层沿用原奖励验收和退出流程。
