# Yuzi · Dalamud 插件库

本库当前发布基于原作者新版重新接入扩展的 NewFolder3，提供对应源码、许可证和校验信息。

## 添加插件库

在卫月第三方插件仓库设置中添加以下地址，保存并刷新：

```text
https://raw.githubusercontent.com/yuanzil1243-oss/DalamudPlugins/main/pluginmaster.json
```

## 更新与保留数据

- 升级前先停止探索并停用旧 NewFolder3 开发加载项，再通过本库安装或更新；同一时间只启用一个 NewFolder3。
- **不要删除** `pluginConfigs/NewFolder3.json` 或同名配置目录。新版先备份再迁移已知旧模式值，保留地图缓存和暂停/续打记录。
- 内置移速默认关闭，Boss 层、副本外及任务停止时释放。请勿同时启用其他移速工具。
- “下底领奖后自动退本删档循环”默认关闭，位于说明页移速、防踢下方；只清理本任务创建并校验匹配的存档，按已有循环设置重开，已有存档与当前副本续接保档停止。
- 两套地图随包提供，保留签名与哈希验证；没有恢复原作者私人服务器的自动同步接口。
