# 构建与扩展维护

当前版本 `.2206`，基于官方 `.22`，提交 `e578aaec1b58945a8bf6868a5c8ec2baae8bc50b`。

`NewFolder3/` 提供完整构建源码与固定版本 OmenTools。准备 SDK10.0.401 和国服 Dalamud API15 开发程序集，从该目录执行：

```powershell
dotnet build NewFolder3.csproj -c Release -p:Platform=x64
dotnet run --project tests/NewFolder3.ContractTests -c Release -p:Platform=x64
dotnet run --project tests/NewFolder3.SpeedChecks -c Release
powershell -ExecutionPolicy Bypass -File tests/Test-VersionSwitch.ps1
```

产物在 `artifacts/bin/NewFolder3/release/`。OmenTools 源文件已提供，直接构建无需初始化子模块；个人配置和宿主 SDK 不随包提供。

## 更新扩展壳

新增实现位于 `LocalExtensions/`，通过 `Directory.Build.targets` 接入。继续探索宝箱配置由 CurrentDutyChestSettings 按实际地宫保存，CurrentDutyResumeScenario 校验活动上下文后更新原运行快照；Farming 界面只分派续接设置，不改变普通模式限制或配置。AE 加载名兼容由 AePluginIdentity 提供界面识别；四个 IPC 名称保留原前缀。RotationControlDiagnostics 令 AE／Custom 控制记录跳过插件清单和版本，并只隔离可选元数据／回放日志异常；实际 IPC 控制、失败停止及主循环移速故障保护保持原逻辑。17 项新增回归及对应测试随壳导出。移速策略及短租约统一放行已验证 Result 层，仍要求运行、稳定、可走和区域匹配。官方 .22 新道具文件及接入原样保留。GCD 保护为独立观测与单次状态机；跨模式暂停业务在 partial 扩展中，官方 FarmingScenario 只增加两个调度调用，Pause 入口分派新记录，旧继续路径保留。35 个声明接入文件及 80 个扩展文件随壳导出，323 项契约、102 项移速检查及干净重套后完整构建通过。新增游戏流程尚待实战；不声称修复 Boss 初始化根因。下底领奖后收尾由独立策略及配置实现，仅在 RunHost 的原版终局停留分支增加一个可选调用；奖励领取、拥有档清理和循环计数仍使用原实现。发布目录的 `NewFolder3-overlay.zip` 包含上下文补丁、新增文件及哈希。准备独立官方 Git 工作树，再按 `NewFolder3/docs/本地扩展壳与更新规则.md` 使用 `local_overlay.py apply`，输出到新目录；上游冲突时停止。

当前仓库为发布仓库，不含官方基底的 Git 历史。`export` 和 `verify_local.py` 的基底审计须在独立官方工作树执行，不能误用本仓库根目录。套用成功仍需构建、回归及游戏验证。

版本最后一段 = 官方最后一段 ×100 + 本地修订号：`.20 → .2001/.2002`，`.21 → .2101/.2102/.2103`，`.22 → .2201/.2202/.2203/.2204`。
