# NewFolder3 0.7.55.38 测试版

发布日期：2026-11-17；作者：John Smith / Yuzi。

本版以公开测试版0.7.55.36为基线，仅修复下列两项。正式版继续为0.7.55.35；开发区尚未发布的0.7.55.37地图下载改动不在本包内，因此测试版本直接递增至0.7.55.38。

## 存档清理选择正确的菜单项

运行记录两次在通关30层、退本完成后，删档阶段读到“解散固定队伍并转换为随机组队存档”的提示。该提示对应本地Addon10410，预期删除确认对应10412。旧代码固定发送入口菜单参数3；目前不能仅凭日志确定测试者当时的全部菜单顺序。

现在读取当前入口菜单，按“重置攻略进度”等明确语义查找唯一选项，并派发该实际列表行的原生点击。不会根据是否通关来猜测新的固定序号。找不到、读不到或有多个匹配时不选择；沿用有界清理预算，并记录owned-save-delete-menu事件及完整菜单文字。

删除前的本任务存档归属校验、确认提示10412检查、单次确认及槽位清空验收保留。转换存档、解散队伍、未知确认不会被当作删除确认接受。

## 运行期间锁定宝藏探索开关

“探索埋藏的寶藏”在FSD任务执行期间禁用；同一任务暂停、十层组交接及失败重试时保持原选择。任务停止或结束后，可为下一任务重新设置。

运行会话同时拒绝修改该选项，避免从其他调用绕过界面锁定。其他原本允许实时调整的补给箱设置保持原有规则。此次没有改动战斗位置恢复、选敌、寻路或卡死处理。
