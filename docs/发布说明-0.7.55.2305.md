# NewFolder3 0.7.55.2305

基于官方 .23，修复跨地宫地图读取，优化共同覆盖盲踩，新增自由探索指定盲踩层数与聚魔柄用药策略。沿用原库链，名称仍为 NewFolder3。

- 地图按地宫、区域与楼层验证。修复死宫51层聚魔柄找宝误读妖宫详细地图造成的楼层越界与停顿；天宫也不再串用妖宫地图。适用的妖宫详细地图与其他场景Palantir本地点回退保持。
- 同房间候选按水平1.8米共同覆盖合并，并验证可到达、原始点全部在覆盖内；不把两两相交的长点链强行合并。保留停留和新扫描确认，不增加先试踩再逐点补踩步骤；准确点与箱子沿原流程。
- 自由探索勾选找宝后可选“只盲踩指定层数”，填写起止层。范围内盲踩并优先感知；范围外不盲踩，仅在金箱感知溢出时用感知，已有准确点和箱子仍处理。默认关闭，运行中范围不变，下次启动生效。
- 聚魔柄：强化自身、妖宫加速有货且无效果即用。天宫弱化留1个给Boss，第2个下一普通层用，第9层拿到第2个则当层用。妖宫安宁留1个给Boss，多余普通层可用；开门开图、清小怪杜松香沿用既有普通层提速流程。天宫魔石规则保持。
- 新增用药只作用于聚魔柄，指定盲踩范围只作用于自由探索；普通下底、死灵术士的起点、目标、领奖、退本、删档和循环决定保持。Boss、选敌与移动策略保持，只在原允许用药的入口补聚魔柄弱化。
- 保留移速与最大加速度、GCD保护、防踢、防击退、强制移动、AE目标协调、模式续打、保档、暂停和失败重试。功能开关均放在底部说明上方；两套2026-11-25.1原签名详细地图随包，更新不删除配置、缓存、暂停记录或游戏存档。
