# NewFolder3 0.7.55.32 尾王测试候选版

整理日期：2026-11-13。已完成编译和自动测试，尚未载入游戏、尚未进行实战验证。

## 99层双Boss

- 平衡限制改为18个百分点，沿用实时最大血量换算和方向判断；只在当前颜色继续攻击会扩大失衡时停手取色，避免按绝对血差来回换色。
- 保留光4560→Grief、暗4559→Eater，以及小怪优先级。战斗中缺色先停手取色，开战前仍可正常发起战斗。
- 无机制占用且存在可核对路线时，先同步暂停BMR，再主动走到对应颜色区域；实际获得角色Buff后才选择对应Boss并恢复输出。
- 吸收以太同时观察Boss、辅助施法者和重叠/连续读条，等待最后施法结束及结算缓冲后重新决策；其他已知移动机制同样优先交给BMR。
- BMR安全接口原生只核对落点。本版另做0.75米分段落点核对和视线检查，每150毫秒复查路线；当前点不安全时由BMR先处理，不能把接口返回值描述成完整寻路保证。
- 取色有35秒非机制时间预算、单次10秒/3秒无推进限制、2秒重试冷却及三次失败边界；失败停手并释放移动，不无限原地尝试。
- 保留安宁。停手、清目标和关闭自动攻击不能撤回已生效DOT、已发出伤害或当前施法。

## AEAssist内置输出

- 自动输出下拉列表加入AEAssist，检查主运行/主动攻击IPC和明确的停手命令。
- 开启：先停手→主运行开启→主动攻击开启→回读→解除停手；关闭：先停手→主动攻击关闭→主运行关闭。
- 服从既有慧敏、机制、换色等输出门控；不把AE目标选择器当作输出开关，也不主动开启目标选择器。
- 停止FSD或退出副本时关闭本次接管的AE状态；AE关闭失败时保留错误，阻止同时启用另一套输出。
- 保留旧提供者枚举值和已有自定义配置；更新后须自行从下拉列表选择AEAssist，不自动迁移现场设置。

## 尾王模式

- 模式列表新增“尾王模式”，专用入口是卓异的悲寂歼灭战，CFC1065、区域1333；不进入深想战，也不从91层存档进入。
- 在朝圣交错路入口NPC选择独立练习挑战和固定队伍；已在该练习场内也可启动。入口未解锁、选项不唯一或无法确认时停止。
- 独立场景不建立、选择或删除存档，不调用普通层探索、宝箱和楼层传送；复用99层目标/换色逻辑。
- 默认一次。成功须收到本次副本通关事件并完成退场；只计尾王练习次数，不计登顶。失败停止，供人工检查；不自动删档重开。
- 记录进入、血量/颜色/施法快照、转火决策、移动交接和结束原因；BMR回放仍须在BMR中启用。

## 验证和边界

- Release x64构建：0警告、0错误。
- 机制/策略测试116项，契约测试70项，退场回归22项，额外本地目录验证2项，共210项；目录验证的72项包含前述70项，不能重复相加。
- 10个颜色采样点均位于保存的参考碰撞多边形内，最小边界距离约0.859米，大于0.25米到达容差。

- 本版没有在游戏中验证菜单点击、主动取色、实际停手和机制交接。练习场测试也不能替代完整1–100层、道具链、领奖及循环验证。
- 没有本次新日志支持的银箱反馈仍待核实；本轮不实现猜测性修补。此前暂缓的20层未致死问题和其他拉怪/阈值策略不在本轮范围。
