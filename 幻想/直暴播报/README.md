# 直暴播报

在战斗中把自己造成的直击、暴击和直击暴击写入 Dalamud 聊天频道。

文案编辑器可以将文本、占位符、聊天图标和自定义颜色逐段组合，并调整顺序。伤害播报提供“技能名称”“触发类型”“伤害数值”占位符；直击、暴击、直暴分别设置文字颜色。图标选择器只列出可以作为字符输出到聊天框的 Dalamud 图标。

默认输出示例：

```text
技能名称 直击 12,345
技能名称 暴击 23,456！
技能名称 直暴 34,567！！
```

战斗/死亡分隔文本和倒计时播报也使用相同的分段文案编辑器。颜色片段可在文案中途更改颜色，三种伤害播报还可分别设置整体文字颜色或恢复游戏默认聊天颜色。

启用“战斗开始倒计时”播报后，插件会在游戏倒计时进入最后 1 秒时输出配置文本和图标。战斗结束或死亡时也会输出配置的分隔文本；死亡同时结束战斗时只输出一次。

输入 `/zhijibao` 切换播报开关，输入 `/zhijibao config` 打开设置，输入 `/zhijibao test` 预览伤害播报格式。

插件只读取游戏本地伤害、飘字与倒计时数据，不会向游戏服务器发送数据。卫月插件库地址见仓库根目录 README。
