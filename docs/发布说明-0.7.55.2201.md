# NewFolder3 0.7.55.2201

日期：2026-11-24。官方基底 0.7.55.22，提交 e578aaec1b58945a8bf6868a5c8ec2baae8bc50b；本版为 .22 基底的第一个修改版。

- 完整保留官方 .22 新增的深层攻略道具策略：按攻略阶段、楼层效果、剩余普通层及库存选择道具，记录选择原因。官方新道具、战斗、探索、寻路、机制和领奖实现原样保留。
- 修复 AE 已连接却显示“未安装”：统一识别当前内部名 AEAssistV3 及旧名 AEAssist，兼容大小写；输出日志也使用同一识别规则。通信仍用原四个 AEAssist.CombatRoutine 端点，开关租约、手动优先、停止恢复及 /aestop 保护不变。AE 不参与 GCD 自动补打。
- 内置移速新增最终奖励 Result 层许可，包括死宫 200、天宫／朝圣 100；仍使用原启用开关与倍率，不增加选项。策略、150ms 租约及 native 回调统一复核，必须 FSD 运行、区域／地宫／楼层匹配、角色可步行且状态稳定；Boss、过场、停止、出本仍撤销。
- 保留 GCD 停滞保护、各模式本组后暂停、保档解除续跑锁定、继续探索、最高起点、自由探索、防踢、终局领奖后自动退本删档循环，以及妖宫 21–30、31–40 两套签名离线地图。
- 插件名始终为 NewFolder3；原库链不变，历史版本继续独立保留。按用户要求，不等待本地试玩，离线检查通过后直接发布；约定本地目录保留同一发布包。
