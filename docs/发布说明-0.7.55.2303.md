# NewFolder3 0.7.55.2303

基于官方 .23，合并失败结算退本续接和 AE 预设目标选择器处理。沿用原库链与干净名称 NewFolder3，PR 和 RSR 预设不变。

- 修复死亡后已显示“最终成绩”，但未收到失败事件而一直等待的问题。必须确认同一角色、同次地宫层段、角色死亡及原生结算窗口，才按失败退出；仅死亡、等待复活或切图不会直接判败。不依赖游戏存档的失败次数。
- 死灵术士、普通下底、自由探索和聚魔柄的失败重试，退本后重新读取本任务原生存档：还能挑战就沿用原档；不能挑战才核验删除本任务档，并按原模式起点重开。失败不占成功轮数。“保留存档”仍为退本保档停止；来源不明或歧义时保留所有档停止。
- AE 预设在输出接管、停手及恢复输出的边界先发送 `/aeTargetSelector off`，避免覆盖本插件的机制目标。使用明确关闭指令，不用切换指令、不按版本号判断。若关闭指令不可用或调用失败，停止接管输出；指令被接受不等于已读取 AE 状态。关闭后通过服务器信息栏的命名条目只读确认Off，隐藏显示不影响读取；允许AE异步更新，超时仍明确开启则停止探索，条目缺失或文案未知只记未确认，不冒充关闭成功。停止后不自动重新打开目标选择器；AE 的 Running/Pull 开关仍按原租用规则恢复。PR 预设保持原样，RSR 仍用 Manual。
- 沿用 .2302 的三地宫最终奖励层、分数板、模式续打、保档、循环和暂停规则。底部简明说明补充失败后的原档续打规则；所有功能控件仍位于说明上方。

638项契约（含31项失败恢复、13项目标选择指令及信息栏回读边界）、162项默认移速离线、Official／Local保数据换版与两套原签名地图检查通过。主树和真实官方 .23 干净重套完整构建均为0错误、36项既有警告；39个声明挂点、117个扩展文件，模拟 .24→.2401及上下文冲突拒绝通过。详见随包验收记录及BUILDINFO。

原作者Boss、机制、战斗、导航、普通层探索、道具及官方.23出口路线实现与.2302保持；内置移速、GCD、防踢和地图实现保持。不删除用户配置、地图缓存或暂停记录，没有安装、重载或操作用户游戏。用户已验证关闭AE目标选择器可排除抢目标，新版自动指令及失败收尾仍待游戏实测。
