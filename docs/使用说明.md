# NewFolder3 0.7.55.2002 使用说明

基于官方 `0.7.55.20` 接入本地扩展。运行环境为 Windows x64、Dalamud API15、.NET10。AEAssist、BMR、vnavmesh 等外部依赖请按实际功能自行准备，不随包分发。

## 安装与升级

1. 先停止探索，在卫月停用旧 NewFolder3；若使用过本地 DLL，关闭旧的 NewFolder3 开发加载项。
2. 添加首页库链，刷新插件列表，安装或更新到 `0.7.55.2002`。
3. 确认只启用一个 NewFolder3。手动加载时完整解压安装包，不要只复制主 DLL 或混用旧依赖。

**不要删除** `%APPDATA%/XIVLauncherCN/pluginConfigs/NewFolder3.json` 或同名目录。旧 `.83` 写入过官方不支持的模式值 4/5，新版在读取前精确备份原文件再迁移，自由探索偏好移入扩展字段；旧尾王模式回到待手动选择状态，不自动开跑。备份位于 `NewFolder3/LocalCompatibilityBackups`，地图缓存及暂停/续打记录保留。

重复入口需先停用。切回已安装的官方版或指定本地 DLL，可在**关闭游戏后**使用包内 `tools/Repair-NewFolder3.ps1`，默认仅检查，参数见包内《使用与换版说明》。游戏运行中使用卫月管理器切换，不要直接编辑其全局配置。

## 功能

- **内置移速**：仅启用和倍率选项，默认关闭；普通层且任务运行时生效，Boss 层、副本外、停止或卸载时释放；下一组按条件重新启用。请停用其他移速工具。
- **AEAssist 输出控制**：沿用独立输出接入和释放边界，不替换官方副本战斗决策。
- **继续探索**：进入深宫且程序未运行时，在“加载/启动 FSD”旁显示；也可输入 `/newfolder3 fsd continue`。无需槽位，直接继续人物当前层组。
- **最高起点普通下底**：使用所选地宫支持并实际解锁的最高新建起点，沿用官方下底及奖励流程。
- **自由探索**：选择合法新建起点、结束层组、循环次数，以及宝藏、金/银/铜箱等偏好，按地宫保存。完成整个所选区间才计一轮，中间十层组和失败不计成功。
- **已有存档**：明确选择有效存档后，仅完成当前一遍并保档停止，不参与删除重建循环，不自动改用其他槽位。未读到数据时先打开对应挑战面板；死宫请打开挑战“死者宫殿”读取数据。
- **本组后暂停**：使用官方已有功能，不重复新增本地实现。
- **防踢开关**：默认关闭；开启后仅在 FSD 运行、位于深宫、非战斗且原地静止 4 分钟时发送当前位置更新包，不改变角色坐标。服务端计时效果尚未完成游戏内验证。

新建起点遵循原版入口及实际解锁条件，不支持任意跳层；其他十层组起点需通过已有存档接续。

## 妖宫详细地图

内置妖宫（朝圣交错路）`21–30`、`31–40` 两套地图，版本 `2026-11-23.1`，覆盖对应组的普通层。原始签名、作用域、模型与哈希验证保持启用。

地图在插件目录原地只读，较新有效官方缓存优先，不覆盖用户缓存。没有恢复原作者私人服务器的自动同步接口，随包数据通过插件更新。其他层段不能视为已有详细地图。
