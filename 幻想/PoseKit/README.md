# PoseKit 简体中文使用手册

PoseKit 用于浏览 Penumbra 动画模组、调整角色姿势偏移、保存预设，并与伙伴配对播放。

## 安装

在 Dalamud 自定义插件仓库中添加：

`https://raw.githubusercontent.com/yuanzil1243-oss/DalamudPlugins/main/pluginmaster.json`

随后搜索 PoseKit 安装。需要动画发现时启用 Penumbra；需要实时偏移时同时启用 SimpleHeels。

## 命令

- `/posekit`：打开或关闭窗口
- `/posekit tfc`：切换自由镜头
- `/posekit sync`：重新同步附近玩家的表情动作

## 基本流程

在“设置”中选择要扫描的 Penumbra 模组并刷新；在“动画”页播放动作；使用“实时偏移”调整位置后，在“预设”页保存。配对后双方选择预设即可共同播放；“骨骼对齐”可自动调整双方身体部位的位置。

上游项目：[RaylaPetal/PoseKit](https://github.com/RaylaPetal/PoseKit)。
