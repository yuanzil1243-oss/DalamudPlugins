- AE 与 Custom 的输出控制诊断跳过插件清单和版本读取；本地 AE 不要求在线仓库或加载清单版本。原 AE IPC、开关租约、手动优先及停止恢复逻辑保留，未改成强制发送 /aestop。
- 新增壳内 RotationControlDiagnostics，只隔离元数据与回放／警告日志故障；其他输出插件缺版本时记录 null。输出成功仍成功，失败仍上报 FailedProvider 并执行原停止策略。
- 原始 installed?.Version.ToString() 在 installed 存在且 Version 为空时的空引用已离线复现。反馈者同一时段完整异常堆栈尚未取得，不能确认其实际全部故障，也不把界面显示版本当成加载器清单版本。
- 真实控制／主循环异常仍受原停止和移速故障保护；不修改移速倍率、楼层／Boss／出本／停止条件，不清故障锁。已锁定的旧会话需停止后卸载旧插件再加载新包。
- 保留 .2202 续接宝箱独立设置和其他既有扩展；两套签名地图不变。名称为 NewFolder3，版本字段统一 .2203。
