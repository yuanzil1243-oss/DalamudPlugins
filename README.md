## 使用规则

- 辅助开关勾选后进入地宫即按各自规则生效，不需启动FSD。出本、过图或死亡时停用；防击退覆盖所有已验证地宫层数，移速仍仅普通层及最终奖励层，含最大加速度。
- 下底领奖后默认退本，再按所选模式、循环次数、保留存档及暂停要求处理。没有任务的手动地宫不会自动创建循环；完全停手请同时关闭GCD保护。
- 完成目标才计循环次数；失败先续原档，不能续才按核验规则重开。保留存档会关闭循环，只处理已核验绑定的任务存档。
- 三项触发次数独立保存，重启更新保留。死宫强化／聚魔柄可选1–50或51–60；三地宫强化模式可选只刷强化、不兑换。
- 保留AE目标协调、续打、暂停、挖宝盲踩、指定找宝层段与模式用药。妖宫21–30、31–40两套2026-11-25.1原签名地图随包，不覆盖玩家已有较新有效缓存。

## 更新和验证

只加载一份NewFolder3，不要删除配置换版；配置、地图缓存、暂停记录、存档及触发计数保留。同类辅助不要重复开启。

主树与真实官方.23干净重套完整构建0错误、36项既有警告；1408项契约、174项移速、1959项强制移动及辅助范围离线、保数据换版与地图验签通过。44挂点、165扩展文件；模拟未来版本不代表真实新上游自动兼容。未安装、重载或操作游戏，实际效果仍需游戏验证。

相对.2306没有修改shared内任何原作者C#文件，原Boss、战斗、选敌、探索、导航及入退本控制器保持。
