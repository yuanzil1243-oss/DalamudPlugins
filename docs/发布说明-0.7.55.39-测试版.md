# NewFolder3 0.7.55.39 测试版

发布日期：2026-11-18；作者：John Smith / Yuzi。

本版基于已发布的0.7.55.38，只调整普通楼层战斗恢复与探索报错后的手动继续。正式版保持0.7.55.35，未发布的.37地图功能不在本包内。

## 战斗恢复计数

旧逻辑把整层历史失败累加到8次，即使中间已恢复输出，后来仍会因历史累计值而停止。本版保留历史次数供诊断，但以连续失败判断楼层上限：确认目标掉血且角色具备射程、两个高度的清晰视线后，重置连续失败计数，只清除成功目标对应阶段的次数。单个目标每阶段最多2次，连续8次失败仍会停止，不会无限自动重试。

未接战和已经接战的失败分别计次。原先未接战时暂时放弃的怪后来进入仇恨列表，可以使用独立的接战恢复预算；不会因为旧黑名单直接放弃已有仇恨。切换目标不会刷新其他目标的预算。移除了仅根据“曾记录过的目标都耗尽”就立即停止的判断，让尚未尝试的候选仍有机会进入选敌流程；60秒未找到目标仍会明确停止。

## 继续探索按钮

平时隐藏。普通楼层的战斗位置恢复耗尽，或60秒找不到可接战目标而报错停止后，保留当前任务并在副本内显示“继续探索”。只有仍在原副本、原楼层、状态读取正常、角色存活、未过图、未失败或完成且计时未归零时可点击。

点击后清理已失败的寻路、追怪、暂时排除目标和连续失败预算，保留本次任务、循环次数、存档归属、原有任务设置、楼层执行器及宝藏/箱子进度；下一帧按实时门状态、仇恨和剩余目标重新规划。不直接强制点门或跳过未完成的工作。按钮点击后隐藏，再次报错时才出现。

报错暂停期间停止移动与输出联动，不销毁会话；宝藏探索开关仍锁定。主动点击“停止”、死亡、团灭、超时退本、正常结束和未知致命错误不能用此按钮复活任务。状态读取异常或过图期间保持停止，避免把临时读不到副本误当成退出。

旧版在报错时已销毁的任务，不能靠安装此版恢复原会话；这个按钮保护的是本版之后发生的可恢复报错。请在合适的非执行状态更新，不在高层现场热重载。

## 验证与边界

Release/x64完整重建0错误、12条既有OmenTools过时API警告，未增加警告屏蔽。机制134、契约179、退场22，共335项离线回归通过，本版新增21项。覆盖94层失败/成功序列、98层未接战转接战、连续上限、按目标计数、继续按钮状态门禁、单次消费及任务/归属/设置保留。七DLL身份、依赖版本与API15另作分发校验。

尚未游戏内验证。重点观察：正常运行时无新按钮；可恢复报错后停止且显示按钮；手动调整站位后点击可继续原楼层；恢复后若门已开，遵循现有目标策略；死亡和退本后不能继续。

本版不保证所有视线、寻路、外部输出插件或几何异常都能自动修复。99层下底与直接尾王模式的移动偏航问题未在本版修复。门已开截图晚于94层停止时刻，尚不能据此确认门状态检测错误。
