# NewFolder3 0.7.55.41 正式版

发布日期：2026-11-18；作者：John Smith / Yuzi。

本版更新正式通道，整合此前.36–.40测试版功能；旧.40测试入口撤下，用户通过原插件库刷新即可接收正式版更新。

## 91–98层躲避后恢复站位

记录同一目标最近一次确认有效输出的位置。BMR躲避结束后，当前站位仍可攻击时继续战斗；确实无法输出时，优先检查返回该位置的路径。返回点最多保留60秒，距离不超过22米，仍须验证所在房间、当前射程/视线、导航终点和沿途未接战怪物，不直接穿越危险区域或盲走原路线。

躲避后的恢复宽限为12秒。候选路径全部被拒时先等待已接战目标靠近或路线条件变化，不立即重复计为失败。玩家移动、目标明显靠近或未接战怪物布局变化时，至少间隔2秒重新评估；无变化的普通恢复失败等待最多8秒后按既有预算处理。没有确认输出时，多次躲避也不能把宽限无限续期，累计窗口最多30秒。

确认输出后结束复位并清理连续失败；仍无法恢复时保留有界报错与副本内“继续探索”入口。本次新增恢复仅用于朝圣交错路91–98层的已接战目标，不修改99层战斗策略。

## 自由探索默认删档，可选择保留

自由探索成功到达所选结束层后，默认完成退本、验证删除本次任务管理的存档，再停止探索；中间十层继续使用原存档。明确选择续用的槽位也执行此默认策略，其他槽位不受影响，来源与身份核验仍保留。

新增“完成后保留存档”选项，默认不勾选，启动后不可修改。勾选后成功结束时保留存档并停止；保留已完成存档时不再自动进入下一轮。该选项不改变失败后的既有删档重试。旧配置没有该字段时采用默认删档。

## 99层首次取Buff固定中心定位

仅修改刚进入99层、尚未开战时的首次取Buff：导航到入口侧光色地板的固定中心，观察到实际Buff后立即交回原有战斗控制。该阶段取消方向输入定位，避免初始导航与普通首领靠近导航竞争。战斗中的换色、转火、控血及机制策略保持原样。

## 已包含的此前功能

包含.36的自由探索挖宝与诊断隔离、.38的动态删档菜单及运行中锁定挖宝开关、.39的报错保留会话与“继续探索”、.40的签名详细地图和公共历史点位下载。详细地图仍只提供21–30、31–40两个层段；其他层段历史候选点不等于完整地图。客户端不自动上传个人数据。

## 验证范围

Release/x64构建，机制134、契约238、退场22，共394项离线回归通过，其中包含3项公共地图数据验收。新增用例覆盖固定取Buff点与移动交接、94层躲避轨迹对应的有界等待与计数、复位路径不引新怪，以及自由探索清理完成前不得停止、显式保档和删档失败保护。

本版修改尚未在游戏内复测。离线测试不能证明所有房间、BMR走位或职业循环均能恢复；请在停止任务后更新，异常时保留运行日志和已结束的BMR回放。
