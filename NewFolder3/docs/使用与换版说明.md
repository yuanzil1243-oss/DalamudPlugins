# NewFolder3 0.7.55.2203 使用与换版说明

基于官方 0.7.55.22，沿用 .2202 扩展壳并保留新道具策略。本版取消 AE 输出记录对安装清单和版本的读取，隔离输出诊断异常；续接宝箱选择及现有全部扩展保留。按用户本次“直接推送”指令发布原库链，未等待游戏内试玩；本地保留相同发布副本，实际 AE 进战与移速待验证。

## .2203：本地 AE 与移速异常保护

- AEAssist 通过已注册的 `AEAssist.CombatRoutine.*` 接口读取并切换输出；支持本地安装，无须在线仓库或版本字段。本次不改变原启用、停手、手动优先及停止恢复行为。
- AE 与自定义指令的输出记录不再枚举插件清单或读取版本。其他输出插件的版本为空也允许记录；可选诊断出错只记录警告，不将输出控制的成功或失败改写为主循环故障。
- 真实控制失败仍按原规则停止；真实主循环异常仍撤销移速。普通层／最终奖励层、Boss、过场、停止与出本的移速条件不变，AE 仍不参与 GCD 补打。
- 已出现“FSD 主循環發生異常”的旧会话带故障锁，更换本地版本时需先停任务并卸载旧插件、再加载新包；只切换输出类型不会清除旧故障锁。先验证普通层进战、停止输出及恢复输出，Boss 与出本仍应恢复默认。
- 原表达式在加载器版本为空时的空引用已离线复现；反馈者实际故障仍须同一时段完整异常堆栈确认。本次没有游戏实战验证。

## 本次换版修复

旧天宫分支曾把“自由探索”写为 Farming.Mode=4、“尾王”写为 5。官方和 1902 仅识别 0–3，因此即使更换 DLL 仍会因 Farming configuration is invalid 无法加载。

2001 在读取旧配置前先按 SHA-256 备份原文件，再转换已知旧值。自由探索设置转存为扩展字段，不再占用官方模式枚举；其他模式和未知未来值不擅自重置。旧尾王模式回到深层攻略待用户手动选择，不自动开跑。备份位于插件配置目录 LocalCompatibilityBackups；程序不会删除地图、暂停记录、研究数据或游戏原生存档。

## .2201：AE V3 与最终奖励层移速

- AE 当前加载名为 `AEAssistV3`，旧检测只认 `AEAssist`，导致插件实际已连接却显示“未安装”。新版统一识别两个精确名称，并兼容大小写；输出日志也使用同一规则获取 AE 版本。
- 本机 AE 附带接口文档仍声明 `AEAssist.CombatRoutine.IsRunning`、`SetRunning`、`IsPullEnabled`、`SetPullEnabled`，因此通信前缀不随加载名改成 AEAssistV3。只有已注册的可读写开关才能被接管；原手动优先与停止后恢复行为不变。
- 内置移速覆盖普通层与最终奖励层：死宫 200、天宫／朝圣 100 等由原生地宫和区域共同确认的 Result 层。保持原启用开关和倍率，无新增选项。
- 必须 FSD 仍在运行、角色可正常步行、原生层数与区域一致且稳定 500ms；Boss、过场、任务停止及副本外立即撤销。普通 Boss 打完仍在同一 Boss 层时不会因此加速；有效最终奖励层才新增许可。
- 完整保留官方 .22 按阶段、负面效果、剩余楼层及库存使用道具的新策略。AE 仍不参与 GCD 自动补打；本次不声称修复先前 Boss 初始化根因。
- 按用户要求，构建及离线检查通过后直接发布，不等待游戏内试玩。加载与实战行为仍待用户运行确认。

## 日常使用

- 移速仅有启用和倍率设置。普通层或最终奖励层且探索程序运行时生效；Boss 层、副本外、停止和卸载时释放；下一组普通层重新生效。请先停用其他移速工具，默认关闭。
- 继续探索按钮在已进入深宫且程序未运行时显示；也可使用 `/newfolder3 fsd continue`。它直接继续当前层组，不要求用户提供槽位。
- 普通下底使用所选深宫支持的最高新建起点。
- 自由探索可选择合法的新建起点、结束层组和循环次数；完整选定区间才算一轮。既有存档只完成当前一遍，绝不自动删除、重建或改用另一槽位。
- 游戏存档数据尚未读取时，先打开对应挑战面板；死宫请打开挑战“死者宫殿”读取数据。
- 防踢开关默认关闭；仅 FSD 运行、深宫内、非战斗且原地静止 4 分钟后发送当前位置更新包，不改变坐标，服务端效果尚待实战验证。
- “下底领奖后自动退本删档循环”位于“说明”页移速、防踢下方，仅有一个开关，默认关闭。开启后，原版确认全部终局奖励已领取，再自动退本并返回入口；只删除本任务新建且校验匹配的存档，确认该槽为空后，按 FSD 已有循环次数或无限循环设置继续。达到次数上限则在本轮退本清理后停止。
- 奖励未确认、任务异常、诊断保留现场时不会由此开关跳过验收或强制收尾；已有存档与“继续探索”仍保档停止，不纳入删档循环。开关关闭时保持官方原有行为，不影响原本就会退本的地宫流程。

## .2103：GCD 停滞保护

“说明”页现有开关下方增加一个“GCD 停滞保护（测试）”开关，默认关闭，不增加技能选择或计时参数。仅在 FSD 有效运行、当前目标与程序批准的存活敌方目标一致、正常允许输出且技能可用并在射程视线内时计时；连续 6 秒没有 GCD 进展，尝试一个本职业基础单体 GCD。正在读条、GCD 冷却、技能排队或动画锁时不计时，换层、换目标、换任务及停止会重置。

同一次停滞只尝试一次，底层调用拒绝也不连续重试；只有观察到后续 GCD 冷却进展，才允许该目标下一次恢复。不切目标、不寻路、不强停移动、不代替完整输出循环。只对能读取开启状态的 RSR / Wrath / Prome 补打；AE 的 `/aestop` 状态不可可靠读回，AE / Custom / INH3 不补打。机制禁攻、暂停及 Boss 模块未就绪时不强制开怪。

日志记录等待原因、尝试动作和 GCD 冷却进展；冷却进展不等于命中证明。先前 30 层的 `BossMod.ActionDefinitions` 初始化异常根因仍待完整内部异常定位，本开关不能保证恢复该故障。

## .2103：本组后暂停与保档解锁

- 运行时使用“本组十层出本后暂停”，覆盖三深宫的深层攻略、最高起点普通下底、自由探索，以及妖宫挖宝、准备档采集／发现模式。诊断保留现场模式不加入自动收尾。
- 深层攻略的中间组完成后，验证下一组原存档并暂停；不增加循环次数。挖宝及范围终点先完成原模式规定的收尾，再保存下一轮任务和已完成次数。准备档按原模式采集结束点出本并验证保留源档，不强行推进到 Boss。
- 任务最后一轮或已有档终点完成后正常停止，不生成多余续跑锁。失败／异常时保档停止，不因暂停请求重试或删档。最终房仍须原版确认全部领奖，才响应本组后暂停退出。
- “继续”恢复原任务及轮数。中途／准备档继续前仍按角色、职业、槽位和原始存档内容精确核验；挖宝继续保留原详细地图选择。
- 在副本外、自动化已停止后，可点“解除续跑锁定（保留存档）”，然后另选存档／模式。只把本地续跑记录移至插件配置目录的 `FsdPauseArchive/`；游戏存档、地图、配置都保留。原存档仍可之后手动选取。
- 新暂停记录为 `FsdFloorsetPause.json`，原版 `FsdProgressionPause.json` 的继续及解除仍兼容；记录变化或归档失败时不放开锁。副本内“继续探索”仍只续接当前组，出本保档停止，不建立跨组锁定。

## 详细地图

内置妖宫 21–30 和 31–40 两套原始签名地图，数据版本 2026-11-23.1。新用户离线可用；用户已有更新且有效的数据时优先使用。内置文件在插件目录直接读取，不覆盖用户缓存。此包没有恢复原作者私人服务器的自动下载接口。

地图目录取自卫月提供的主插件实际安装位置，兼容卫月将依赖程序集从流中加载的方式；不依赖游戏工作目录，也不要求删除已有配置。

## 保数据切换与更新

不要删除 pluginConfigs/NewFolder3.json 或整个 NewFolder3 配置目录。安装目录中的旧 .83 与官方 .20 同名，不能仅复制一个新 DLL 后让加载器自行选择。

关闭游戏后，可用包内 tools/Repair-NewFolder3.ps1：

```powershell
# 默认只检查；不写入。
powershell -ExecutionPolicy Bypass -File .\tools\Repair-NewFolder3.ps1
# 切回已安装的官方版：禁用本地开发加载项、保留配置、隔离旧 .83 二进制。
powershell -ExecutionPolicy Bypass -File .\tools\Repair-NewFolder3.ps1 -Mode Official -Apply
# 使用新本地版：替换为实际 DLL 完整路径。
powershell -ExecutionPolicy Bypass -File .\tools\Repair-NewFolder3.ps1 -Mode Local -LocalDll 'C:\Plugins\NewFolder3\NewFolder3.dll' -Apply
```

工具先校验备份，再修改 NewFolder3 的加载选择；其他插件保持原设置。旧二进制移入 XIVLauncherCN/backups/NewFolder3-switch-*，不删除。配置目录、地图缓存和续打记录保持原位。写入失败会尝试恢复本次修改。若要手动恢复配置备份，也必须先关闭游戏。

游戏运行时使用卫月插件管理器先卸载旧 NewFolder3，再加载目标版本；不要直接编辑正在运行的卫月全局配置。不要同时启用多个 NewFolder3。通过本库安装时使用当前发布包，停用旧的开发加载入口；构建工具本身不自动发布库链。

版本规则：官方 .20 的第 1、2 个修改版为 .2001、.2002；官方 .21 的第 1、2、3 个修改版为 .2101、.2102、.2103；官方 .22 的第一个修改版为 .2201。更新扩展壳会先检查补丁上下文；发生上游冲突时停止，不覆盖原作者代码。

## .2202：继续探索的宝箱选择

在深宫内点击“继续探索”后，可自行启停金、银、铜箱；不再套用死灵术士模式的禁用规则。修改会更新运行选项快照，影响后续目标选择，不强制中断已经发出的开箱交互。

选项保存在现有配置的 `Fsd.Farming.CurrentDutyChestProfiles`，按实际所在深宫区分，更新／重载／重登后再次继续时复用。首次没有续接记录时，只从同地宫当前模式已有的宝箱选择复制初始化；没有可靠记录则沿用开金、开银、关铜的旧续接默认值，铜箱仍可手动启用。更新前没有保存的临时选择不能恢复。

这份记录与普通模式、最高起点及自由探索配置独立，不授予埋藏宝藏搜索、循环删档或改变原模式限制的权限。续接仍只完成当前十层组后正常出本保档停止。保存失败会提示本次已生效但尚未持久化；首次无法保存则不启动任务。实际开箱与副本内更新续接待游戏验证。
