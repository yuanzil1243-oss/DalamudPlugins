# NewFolder3 0.7.55.2207

基于官方0.7.55.22，修复更新或重新加载后内置移速无法启用的问题。

- 原因：卫月卸载Hook后可能保留入口跳转，.2206的完整函数指纹校验将其误判为游戏函数变化。
- 修复：只读宿主已登记的原始入口前缀，在托管副本补回后继续验证完整567字节SHA-256及两处CALL目标。已知入口跳转和NOP之外的变化、缺少登记或登记异常仍拒绝；不写游戏入口，不调用宿主Unhook或改动其他插件登记。
- 最大加速度继续跟随原移速开关，普通层与最终奖励层许可、Boss层和暂停／停止／出本撤销条件保持。主版不增加额外最大加速度开关。
- 保留.2206聚魔柄过图等待和仅天宫聚魔柄21–30魔石规则，以及GCD、防踢、AE、续接宝箱、循环、暂停和两套地图。官方战斗、探索、寻路及其他功能源码较.2206保持。

升级请正常停用／卸载旧NewFolder3后加载新版，保留配置、地图与暂停记录，不需要删除配置目录；不要同时启用独立移速实验室或其他移速工具。名称保持NewFolder3，原库链不变，旧版发布物仍隔离保留。
