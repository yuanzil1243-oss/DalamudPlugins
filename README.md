# Yuzi · Dalamud 插件库

这里集中发布和维护 Dalamud 插件。每个插件独立提供安装包、源码、使用说明及验证状态；保留原作者署名，Yuzi 的本地修改会在对应说明中标明。

## 添加插件库

在卫月的第三方插件仓库设置中添加以下地址，保存并刷新插件列表：

```text
https://raw.githubusercontent.com/yuanzil1243-oss/DalamudPlugins/refs/heads/main/pluginmaster.json
```

这是 `main/pluginmaster.json` 同一文件的完整分支引用地址。添加一次即可查看本库当前收录的插件，后续新插件继续加入同一库链。

## 使用前确认

- 先阅读所选插件的使用说明，确认适用环境、依赖插件及已知问题。各插件的测试范围不同，以对应发布说明为准。
- 从本地版本切换到库链版本前，先停止该插件任务并停用旧条目，避免同一插件重复加载。需要迁移配置时先备份。
- 手动安装时完整解压对应 ZIP，按该插件说明加载；不要只复制主 DLL 或混用不同版本的依赖。

## 仓库组织

| 内容 | 放置方式 |
| --- | --- |
| 插件库清单 | 根目录 `pluginmaster.json`，每个插件使用独立条目与 InternalName |
| 插件源码 | 按插件名称分目录；当前为 `NewFolder3/` |
| 安装包 | `dist/`，按插件 InternalName 区分 ZIP，新增时不覆盖其他插件 |
| 使用与开发文档 | `docs/`，每个插件分别维护入口；新增插件可使用自己的文档子目录 |
| 许可证与来源 | 原作者及第三方声明随对应插件保留，相关文件见 `LICENSE`、`licenses/` |

新增插件时同步补齐插件列表、库链条目、源码、安装包、说明及对应校验，不在首页堆放完整开发日志。
