# NewFolder3 0.7.55.2203

基于官方 0.7.55.22。本次处理“选择 AEAssist 输出后，普通层一打怪就失去内置移速；自定义指令正常”的反馈。

- AE 使用原 `AEAssist.CombatRoutine.*` 接口控制，只要求对应接口可用，支持本地安装。输出记录不再读取 AE 安装清单或版本号；自定义指令同样不依赖这些信息。
- 可选输出诊断、回放或警告日志出错，不再向主循环冒泡，也不会修改实际输出控制的成功／失败。其他输出插件版本缺失时允许记录空值。
- 原 AE 开关租约、手动优先和停止恢复保留；不强制发送 `/aestop`，不为 AE 加入 GCD 补打。真实控制失败仍停止，真实主循环异常仍撤销移速。
- 普通层和最终奖励层的移速许可保持原条件；Boss、过场、不能步行、停止及副本外仍撤销。保留 .2202 续接金银铜箱独立选择、官方 .22 道具策略、现有扩展及两套签名地图。
- 已离线复现原日志表达式遇到空版本号时的空引用；尚未取得反馈者同一时段完整异常堆栈，不把代码复现等同于确认其所有实际故障。

当前源码及官方基底干净重套源码均通过 Release/x64 构建（0 错误、36 项上游既有警告）、259 项契约、102 项移速检查及保数据换版检查；76 个扩展文件、35 个接入文件，模拟下一版本及代码冲突拒绝通过。原战斗、探索、道具、寻路、机制、奖励及移速实现未因本次修复改动。

按用户本次“直接推送”指令发布，未等待游戏试玩。实际 AE 进战、移速与跨层恢复仍待验证；未操作游戏、未清配置或地图。旧会话若已有“FSD 主循環發生異常”故障锁，先停止任务并卸载旧插件再加载本版，不能只切换输出类型。插件名仍为 NewFolder3，沿用原库链；旧版本保持独立。
