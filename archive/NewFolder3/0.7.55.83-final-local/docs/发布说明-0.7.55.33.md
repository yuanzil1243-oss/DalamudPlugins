# NewFolder3 0.7.55.33：尾王固定队伍确认修复

日期：2026-11-13。基于0.7.55.32，范围仅为尾王入场确认遗漏。

用户截图证实入口在选择“固定队伍”后，还会出现“确定以\"固定队伍\"进入吗？”的SelectYesno确认框。0.7.55.32缺少这一步处理，将它当成未知提示而停止。

本版补上该确认：只有本次流程已经选择正确的尾王挑战、随后选择固定队伍，且弹窗全文与截图中的固定队伍入场提示匹配时，才发送“是”。确认框先于仍可见的父菜单处理；发送后等待关闭，避免重复确认。文字未就绪会有限等待；读取、发送或窗口关闭超时会停止并记录原因。

随机组队、删档、退本、夹带其他文字的弹窗仍不确认。新任务不会接管旧任务遗留的确认框；更新后先手动点“否”退出旧弹窗，再重新启动尾王模式，或手动进入正确的练习场后再启动。

99层血差/主动取色、AE输出和无存档尾王模式沿用0.7.55.32。没有操作游戏、改加载路径或重载插件；0.7.55.33须由用户加载后复测。
